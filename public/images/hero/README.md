# Hero Visual Assets Directory

This directory stores the primary visual imagery for the Hero Section of Aishwarya Redevelopment Advisory Company.

## Requirements for Official Hero Asset
- **Recommended Filename**: `hero-redevelopment-mumbai.webp` or `hero-redevelopment-mumbai.jpg`
- **Subject**: High-resolution architectural photography of a landmark Mumbai redevelopment project, master plan elevation, or urban architectural silhouette at twilight.
- **Dimensions**: 2560x1440px or 3840x2160px (16:9 ratio, Retina optimized)
- **Format**: Optimized WebP or progressive JPEG (maximum 400KB - 750KB compressed)
- **Status**: OFFICIAL CLIENT HERO ASSET PENDING — Currently utilizing a temporary architectural visual fallback (`hero-architecture-fallback.jpg`).
