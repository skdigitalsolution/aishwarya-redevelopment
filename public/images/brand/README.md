# Brand Assets Directory

Place corporate brand identity assets here for Aishwarya Redevelopment Advisory Company.

## Recommended Specifications

### 1. Primary Wordmark & Logo (`logo.svg`, `logo-light.svg`, `logo-dark.svg`)
- **Format**: Vector `.svg` (preferred) or high-resolution transparent `.png` (minimum 3x retina, width 1200px+)
- **Variants**:
  - `logo-light.svg`: For Ivory / Light surfaces (Deep Navy `#0B1D3A` typography with Muted Gold `#C6A66B` crest)
  - `logo-dark.svg`: For Deep Navy surfaces (Warm Ivory `#F8F6F1` typography with Radiant Gold `#DFCA9E` crest)

### 2. Monogram / Insignia (`monogram.svg`)
- **Format**: Vector `.svg` or 512x512 transparent `.png`
- **Use Case**: Favicon, watermarks, mobile headers, seal of advisory excellence

### 3. Favicon & Web App Icons
- `favicon.ico`: Multi-size (16x16, 32x32, 48x48)
- `apple-touch-icon.png`: 180x180 PNG
