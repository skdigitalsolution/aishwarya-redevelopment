# Client Images & Society Portfolio Directory

This directory hosts client-related visual assets for Aishwarya Redevelopment Advisory Company.

## Asset Categories

### 1. Housing Society & Committee Photographs
- **Format**: High-resolution `.webp` or `.jpg`
- **Resolution**: 1600x1000px minimum (16:10 or 3:2 landscape ratio)
- **Subject matter**: Cooperative housing societies, general body meetings, signing ceremonies, key handover celebrations.

### 2. Client & Partner Logos
- **Format**: Vector `.svg` or transparent `.png` (monochrome or gold-tinted)
- **Dimensions**: Scaled to 240x80px bounding box
- **Usage**: Trust badges, client partner ticker, committee endorsements.
